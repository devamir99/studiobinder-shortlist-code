زبان سینما، به زبان کد

این سند مرجعی تعاملی بر اساس سری آموزشی The Shot List از کانال StudioBinder است؛ ده قسمت درباره‌ی اندازه نما، کادربندی، زاویه، عمق میدان، ریگ، حرکت دوربین، لنز، فریم‌ریت، ترنزیشن و تدوین. هر مفهوم از نگاه یک کریتیو دولوپر بررسی شده است: هدف آن چیست، چه حسی می‌سازد، کجا در وب و تجربه‌های تعاملی به کار می‌آید، و دقیقاً با چه کدی در Three.js، GSAP، CSS یا GLSL پیاده می‌شود.

00 · INTRODUCTION

چرا یک دولوپر باید سینما بداند؟

هر سین Three.js یک فیلم‌برداری است، هر اسکرول یک حرکت دوربین، و هر تغییر صفحه یک «کات». فیلم‌سازها صد سال است که روی این سؤال کار کرده‌اند: چطور نگاه مخاطب را هدایت کنیم و به او حس بدهیم؟ وقتی واژگان سینما را بلد باشید، به‌جای «دوربین را یک‌کم ببر جلو» می‌گویید «یک Push-in آرام با لنز ۵۰ تا MCU» و دقیقاً می‌دانید چه کدی بنویسید.

🎯

هدف این سند

تبدیل هر اصطلاح سینمایی به یک «الگوی کد» قابل استفاده؛ مرجعی که هنگام طراحی سین، موشن یا ترنزیشن کنار دستتان باشد.

پایه‌ی کد: یک دوربین مجازی «سینمایی» Camera State Pattern

همه‌ی دموهای این سند روی یک الگوی ساده ساخته شده‌اند: دوربین را با یک آبجکت وضعیت توصیف می‌کنیم (موقعیت، نقطه‌ی هدف، رول، فاصله‌ی کانونی) و هر حرکت سینمایی فقط tween کردن همین اعداد با GSAP است. این جدا کردن «داده» از «اعمال روی دوربین» باعث می‌شود حرکت‌ها قابل ترکیب، قابل اسکراب با اسکرول و قابل ذخیره به‌شکل JSON باشند. 


            import * as THREE from 'three';
            import gsap from 'gsap';

            const camera = new THREE.PerspectiveCamera(40, innerWidth / innerHeight, 0.05, 400);
            camera.filmGauge = 36;      // عرض سنسور فول‌فریم (mm) ⇒ فاصله‌ی کانونی‌ها مثل لنز واقعی

            // وضعیت دوربین: تمام «زبان سینما» در همین چند عدد است
            const cam = {
              x: 0, y: 1.6, z: 5,          // موقعیت (متر) — ارتفاع چشم انسان ≈ 1.6
              tx: 0, ty: 1.5, tz: 0,       // نقطه‌ای که به آن نگاه می‌کنیم
              roll: 0,                     // درجه (Dutch angle / Roll)
              focal: 35,                   // فاصله‌ی کانونی (mm)
              shiftX: 0, shiftY: 0,        // جابه‌جایی کادر (Lens shift / ترکیب‌بندی)
            };

            function applyCamera() {
              camera.position.set(cam.x, cam.y, cam.z);
              camera.lookAt(cam.tx, cam.ty, cam.tz);
              camera.rotateZ(THREE.MathUtils.degToRad(cam.roll));
              camera.setFocalLength(cam.focal);           // fov را خودش حساب می‌کند
              if (cam.shiftX || cam.shiftY) {
                const W = 1000, H = W / camera.aspect;
                camera.setViewOffset(W, H, cam.shiftX * W, cam.shiftY * H, W, H);
              } else camera.clearViewOffset();
            }

            // حرکت دوربین = tween ؛ کات = set
            const moveTo = (state, opts) => gsap.to(cam, { ...state, duration: 1.6, ease: 'power2.inOut', ...opts });
            const cutTo  = (state) => gsap.set(cam, state);

            renderer.setAnimationLoop(() => { applyCamera(); renderer.render(scene, camera); });
          

            // ریاضی لنز — همان فرمول‌های عکاسی
            const DEG = Math.PI / 180;

            // ۱) فاصله‌ی کانونی ⇒ زاویه‌ی دید عمودی (برای سنسور با ارتفاع filmH)
            const vfov = (focalMM, filmH = 36 / camera.aspect) => 2 * Math.atan(filmH / (2 * focalMM)) / DEG;

            // ۲) چه فاصله‌ای لازم است تا ارتفاع h (متر) کل کادر عمودی را پر کند؟
            const distanceForHeight = (h, fovDeg) => (h / 2) / Math.tan((fovDeg * DEG) / 2);

            // ۳) زاویه‌ی دید افقی از عمودی
            const hfov = (vfovDeg, aspect) => 2 * Math.atan(Math.tan((vfovDeg * DEG) / 2) * aspect) / DEG;

            // مثال: لنز 50mm روی 16:9 ⇒ vfov ≈ 22.9° ؛ برای Medium Shot (h≈0.9m) ⇒ d ≈ 2.22m

            gsap.registerPlugin(ScrollTrigger);

            // یک «سکانس» دوربین که با اسکرول کاربر اسکراب می‌شود
            const tl = gsap.timeline({
              scrollTrigger: { trigger: '#story', start: 'top top', end: '+=3000', scrub: 1, pin: true },
            });
            tl.to(cam, { z: 9, y: 4, ty: 1, duration: 1 })            // Crane up — Establishing
              .to(cam, { z: 2.2, y: 1.6, ty: 1.4, duration: 1 })      // Push in تا MS

            const BODY = { top: 1.75, eyes: 1.65, chin: 1.52, chest: 1.25, waist: 1.0, thigh: 0.62, feet: 0 };

            const SHOT_SIZES = {
              FS:  [-0.08, 1.92],   // [پایین کادر، بالای کادر] با کمی Headroom و Footroom
              MWS: [0.55, 1.88],
              MS:  [0.95, 1.86],
              MCU: [1.24, 1.84],
              CU:  [1.44, 1.81],
              ECU: [1.60, 1.705],
            };

            function frameSubject(camera, subject, [bottom, top]) {
              const h = top - bottom;
              const fov = THREE.MathUtils.degToRad(camera.fov);
              const d = (h / 2) / Math.tan(fov / 2);          // فاصله‌ی لازم
              const cy = subject.position.y + (bottom + top) / 2;
              return { x: subject.position.x, y: cy, z: subject.position.z + d, tx: subject.position.x, ty: cy, tz: subject.position.z };
            }

            moveTo(frameSubject(camera, actor, SHOT_SIZES.MCU));
          

            // برای مدل‌های دلخواه (GLTF): کادربندی بر اساس Bounding Box
            function fitToObject(camera, object, padding = 1.15) {
              const box = new THREE.Box3().setFromObject(object);
              const size = box.getSize(new THREE.Vector3());
              const center = box.getCenter(new THREE.Vector3());
              const vfov = THREE.MathUtils.degToRad(camera.fov);
              const hfov = 2 * Math.atan(Math.tan(vfov / 2) * camera.aspect);
              const distV = (size.y * padding / 2) / Math.tan(vfov / 2);
              const distH = (size.x * padding / 2) / Math.tan(hfov / 2);
              const d = Math.max(distV, distH) + size.z / 2;   // هر کدام محدودکننده‌تر است
              return { x: center.x, y: center.y, z: center.z + d, tx: center.x, ty: center.y, tz: center.z };
            }

            // Over-the-shoulder: پشت و کمی کنار شانه‌ی A، رو به صورت B
            function overShoulder(A, B, side = 1) {
              const a = headOf(A), b = headOf(B);
              const dir = b.clone().sub(a).normalize();
              const right = new THREE.Vector3().crossVectors(dir, THREE.Object3D.DEFAULT_UP);
              const pos = a.clone().addScaledVector(dir, -0.9).addScaledVector(right, 0.35 * side).add(new THREE.Vector3(0, 0.05, 0));

EPISODE 04 · DEPTH OF FIELD

عمق میدان و فوکوس Depth of Field

عمق میدان (DOF) محدوده‌ای از فاصله‌هاست که در تصویر واضح دیده می‌شود. سه عامل آن را کنترل می‌کنند: دیافراگم (f-stop کوچک‌تر ⇐ عمق کمتر)، فاصله‌ی کانونی (لنز بلندتر ⇐ عمق کمتر) و فاصله‌ی فوکوس (سوژه‌ی نزدیک‌تر ⇐ عمق کمتر). DOF قدرتمندترین ابزار برای گفتن «اینجا را نگاه کن» است.

🎯

            import { EffectComposer } from 'three/addons/postprocessing/EffectComposer.js';
            import { RenderPass } from 'three/addons/postprocessing/RenderPass.js';
            import { BokehPass } from 'three/addons/postprocessing/BokehPass.js';
            import { OutputPass } from 'three/addons/postprocessing/OutputPass.js';

            const composer = new EffectComposer(renderer);
            composer.addPass(new RenderPass(scene, camera));
            const bokeh = new BokehPass(scene, camera, {
              focus: 3.0,       // فاصله‌ی فوکوس (واحد صحنه = متر) در امتداد دید دوربین
              aperture: 0.01,   // شدت (بزرگ‌تر = دیافراگم بازتر)
              maxblur: 0.016,   // سقف بلور (درصد از کادر)
            });
            composer.addPass(bokeh);
            composer.addPass(new OutputPass()); // تون‌مپینگ و sRGB در پایان

            renderer.setAnimationLoop(() => composer.render());

            // Rack focus
            gsap.to(bokeh.uniforms.focus, { value: 7.3, duration: 1.4, ease: 'power2.inOut' });
          

            // محاسبه‌ی واقعی (برای اینکه پارامترهای «عکاسی» به UI بدهید)
            const COC = 0.03; // دایره‌ی ابهام مجاز فول‌فریم (mm)
            function depthOfField(focalMM, N, focusM) {
              const f = focalMM / 1000, c = COC / 1000, s = focusM;
              const H = (f * f) / (N * c) + f;                         // هایپرفوکال
              const near = (s * (H - f)) / (H + s - 2 * f);
              const far  = s >= H ? Infinity : (s * (H - f)) / (H - s);
              return { H, near, far, total: far - near };
            }
            depthOfField(85, 1.4, 3);  // ⇒ ~ 2.96m تا 3.04m  (فقط ۸ سانت!)
            depthOfField(24, 11, 3);   // ⇒ ~ 1.1m تا ∞

            // نگاشت تقریبی به BokehPass: CoC ∝ f² / (N · s)
            bokeh.uniforms.aperture.value = (f * f) / (N * s * (s - f) * filmHeight) * k;
          

            // فوکوس خودکار روی چیزی که کاربر به آن اشاره می‌کند (Autofocus)
            const ray = new THREE.Raycaster();
            addEventListener('pointermove', (e) => {
              const p = new THREE.Vector2((e.clientX / innerWidth) * 2 - 1, -(e.clientY / innerHeight) * 2 + 1);
              ray.setFromCamera(p, camera);
              const hit = ray.intersectObjects(scene.children, true)[0];
              if (!hit) return;
              // BokehPass فاصله را در امتداد محور دید می‌خواهد (نه فاصله‌ی اقلیدسی)
              const viewZ = hit.point.clone().applyMatrix4(camera.matrixWorldInverse).z;
              gsap.to(bokeh.uniforms.focus, { value: -viewZ, duration: 0.6, ease: 'power3.out', overwrite: true });
            });
          

            /* لایه‌ها به‌عنوان «فاصله»: هرچه دورتر از لایه‌ی فوکوس، محوتر */
            .layer { filter: blur(calc(var(--depth-delta) * 6px)); transition: filter .6s; }

            /* Shallow DOF برای مودال: پس‌زمینه محو و تیره */
            .modal-backdrop { backdrop-filter: blur(14px) brightness(.6) saturate(1.2); }

            /* Rack focus بین دو ستون */
            .split[data-focus="left"]  .right,

            // damp مستقل از فریم‌ریت است (برخلاف lerp ثابت مثل x += (t - x) * 0.1)
            // lambda کم ⇒ فنر نرم (Steadicam) ؛ lambda زیاد ⇒ سفت (Gimbal)
            const { damp } = THREE.MathUtils;
            function followRig(dt, actor, { lambda = 1.6, offset = new THREE.Vector3(0, 1.7, -2.6) } = {}) {
              const desired = actor.localToWorld(offset.clone());
              cam.x = damp(cam.x, desired.x, lambda, dt);
              cam.y = damp(cam.y, desired.y, lambda, dt);
              cam.z = damp(cam.z, desired.z, lambda, dt);
              const look = actor.localToWorld(new THREE.Vector3(0, 1.4, 1.5));   // کمی جلوتر از بازیگر
              cam.tx = damp(cam.tx, look.x, lambda * 1.3, dt);
              cam.ty = damp(cam.ty, look.y, lambda * 1.3, dt);
              cam.tz = damp(cam.tz, look.z, lambda * 1.3, dt);
            }
          

            import { createNoise2D } from 'simplex-noise'; // یا یک value-noise ساده
            const noise = createNoise2D();
            const fbm = (x, seed) => noise(x, seed) * 0.6 + noise(x * 2.1, seed + 9) * 0.3 + noise(x * 4.3, seed + 17) * 0.1;

            function handheld(t, intensity = 1) {
              // بعد از lookAt اعمال شود — در فضای محلی دوربین
              camera.translateX(fbm(t * 1.3, 0) * 0.045 * intensity);
              camera.translateY(fbm(t * 1.1, 1) * 0.035 * intensity + Math.sin(t * 9) * 0.006); // تنفس/قدم
              camera.rotateX(fbm(t * 0.9, 2) * 0.02 * intensity);
              camera.rotateY(fbm(t * 0.7, 3) * 0.02 * intensity);
              camera.rotateZ(fbm(t * 0.8, 4) * 0.025 * intensity);
            }
            // Trauma-based shake (برای ضربه/انفجار): intensity = trauma², و trauma در هر فریم کم شود
          

            // ریل دالی = یک منحنی؛ دوربین فقط پارامتر u ∈ [0,1] را دارد

              new THREE.Vector3(-6, 1.4, 3.6), new THREE.Vector3(-2, 1.4, 4.2),
              new THREE.Vector3(2, 1.6, 3.4),  new THREE.Vector3(6, 1.4, 3.8),
            ]);
            const rig = { u: 0 };

            // اتصال ریل به اسکرول — «Camera on rails»
            gsap.to(rig, { u: 1, ease: 'none', scrollTrigger: { trigger: '#gallery', scrub: 1, pin: true, end: '+=4000' } });

            renderer.setAnimationLoop(() => {
              const p = track.getPointAt(rig.u);
              camera.position.copy(p);
              camera.lookAt(track.getPointAt(Math.min(rig.u + 0.02, 1)).add(new THREE.Vector3(0, -0.2, -4)));
            });
          

            // Crane: انتهای بازوی L حول pivot
            const a = 0.45 + Math.sin(t * 0.3) * 0.65;
            camera.position.set(pivot.x, pivot.y + Math.sin(a) * L, pivot.z - (1 - Math.cos(a)) * L);

            // Drone orbit
            const ang = t * 0.12;
            camera.position.set(target.x + Math.cos(ang) * 12, 9, target.z + Math.sin(ang) * 12);
            camera.lookAt(target);

            // Snorricam: دوربین فرزند بازیگر ⇒ همه‌ی حرکت‌ها و چرخش‌های او را به ارث می‌برد
            actor.add(camera);
            camera.position.set(0, 1.66, 0.75);
            camera.lookAt(actor.localToWorld(new THREE.Vector3(0, 1.6, 0)));
          

            // اسلایدر کوچک که به ماوس واکنش نشان می‌دهد — رایج‌ترین «ریگ» در هیروی سایت‌ها
            const mouse = { x: 0, y: 0 };
            addEventListener('pointermove', (e) => {
              mouse.x = (e.clientX / innerWidth) * 2 - 1;
              mouse.y = (e.clientY / innerHeight) * 2 - 1;
            });
            renderer.setAnimationLoop(() => {
              const dt = clock.getDelta();
              cam.x = THREE.MathUtils.damp(cam.x, mouse.x * 0.6, 2.5, dt);   // ±60cm
              cam.y = THREE.MathUtils.damp(cam.y, 1.5 - mouse.y * 0.2, 2.5, dt);
              applyCamera(); renderer.render(scene, camera);
            });

EPISODE 07 · CAMERA LENSES

لنزها و فاصله‌ی کانونی Camera Lenses

فاصله‌ی کانونی (mm) زاویه‌ی دید را تعیین می‌کند؛ اما نکته‌ی کلیدی این است: پرسپکتیو (نسبت اندازه‌ی جلو و عقب) را فاصله‌ی دوربین می‌سازد، نه لنز. لنز واید «مجبورتان می‌کند» نزدیک بروید، پس پرسپکتیو اغراق می‌شود؛ تله «مجبورتان می‌کند» دور بایستید، پس لایه‌ها فشرده می‌شوند (Compression).

فریم‌ریت و شاتر Frame Rate

فریم‌ریت دو معنا دارد: فریم‌ریت ضبط (چند تصویر در ثانیه گرفته می‌شود) و فریم‌ریت پخش. تفاوت این دو، سرعت زمان را می‌سازد (اسلوموشن یا تایم‌لپس). زاویه‌ی شاتر تعیین می‌کند هر فریم چه مدت نور بگیرد و در نتیجه چقدر موشن‌بلور داشته باشد. قانون ۱۸۰ درجه: سرعت شاتر = ۱ / (۲ × فریم‌ریت).

            export function direct(shotList, { scrollTrigger } = {}) {
              const tl = gsap.timeline({ scrollTrigger });
              for (const s of shotList) {
                const subject = scene.getObjectByName(s.subject ?? 'hero');
                const base = {
                  ...frameSubject(camera, subject, SHOT_SIZES[s.size]),
                  ...ANGLES[s.angle],
                  focal: s.focal,
                  roll: s.angle === 'dutch' ? 15 : 0,
                };
                tl.addLabel(s.id);
                if (s.transition === 'cut' || !tl.duration()) tl.set(cam, base);
                else tl.to(cam, { ...base, duration: 1, ease: 'power2.inOut' });

                if (MOVES[s.move]) tl.add(MOVES[s.move](s), '>');            // حرکت داخل نما
                tl.call(() => setRig(s.rig), null, s.id);                         // رفتار ریگ (damp/noise)

                tl.to({}, { duration: s.dur });                                    // نگه داشتن نما
              }
              return tl;
            }
